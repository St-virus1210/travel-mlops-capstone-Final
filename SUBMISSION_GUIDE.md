# AlmaBetter Submission Guide

The acceptance hold message says:

> Please include the Colab Notebook in your submission and ensure that the corresponding GitHub repository link is provided within the notebook.

## Required before resubmission

### Project-level Colab template

Also open and execute `notebooks/00_Project_Template_Colab.ipynb`. This is a populated project-template Colab, not a blank notebook. It provides the project overview, dataset map, notebook map, MLOps components, repository link, and submission checklist.

See `docs/COLAB_SUBMISSION_NOTE.md` for the corresponding submission note.


1. Open these three notebooks in Google Colab:
   - `notebooks/01_Regression_Modeling.ipynb`
   - `notebooks/02_Classification_Modeling.ipynb`
   - `notebooks/03_Recommender_Modeling.ipynb`
2. Run **Runtime → Run all**.
3. Save the executed notebook.
4. Share each notebook so the evaluator can open it.
5. Submit the Colab URL(s) in the AlmaBetter submission form.
6. Confirm each notebook visibly contains this GitHub repository URL:
   https://github.com/St-virus1210/travel-mlops-capstone-2
7. Also provide the GitHub repository URL in the project/repository field if the form asks for it.

## What not to submit by itself

Do not submit only the GitHub repository. The hold reason explicitly requires the Colab notebook in the submission.
